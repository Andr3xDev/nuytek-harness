# Creational patterns

These patterns provide various object creation mechanisms, which increase flexibility and reuse of existing code.

## Factory Method (Also known as: Virtual Constructor)

Provides an interface for creating objects in a superclass, but allows subclasses to alter the type of objects that will be created.

Review [@factory-method](./creational/factory-method.md)

## Abstract Factory

Lets you produce families of related objects without specifying their concrete classes.

Review [@abstract-factory](./creational/abstract-factory.md)

## Builder

Lets you construct complex objects step by step. The pattern allows you to produce different types and representations of an object using the same construction code.

Review [@builder](./creational/builder.md)

## Prototype

Lets you copy existing objects without making your code dependent on their classes.

Review [@prototype](./creational/prototype.md)

## Singleton

Lets you ensure that a class has only one instance, while providing a global access point to this instance.

Review [@singleton](./creational/singleton.md)
